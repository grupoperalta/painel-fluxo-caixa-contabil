# Painel Fluxo de Caixa Contábil — Grupo Peralta

Ferramenta de **revisão da diretoria** para o fluxo de caixa construído pela contabilidade
(partidas dobradas), no layout do relatório do WF Partners.

- **Acesso restrito por senha.** O conteúdo é **cifrado (AES-256)** e só é descriptografado
  no navegador de quem tem a senha (fornecida pela Controladoria). Nada trafega em texto claro.
- Página única, sem servidor — publicada via **GitHub Pages**.
- Recursos: DFC por rubrica/mês, Análise Vertical (AV%) e Horizontal (AH%), reconciliação
  por empresa, e **lançamentos com fornecedor + natureza** (drill-down + busca + marcação de revisão).

> Este repositório contém **apenas** a página cifrada. O motor de cálculo e os dados brutos
> ficam em ambiente privado da Controladoria.

*Grupo Peralta — desde 1966.*
